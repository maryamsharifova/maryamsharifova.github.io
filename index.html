01 / SPEECH

Speech-to-text API for Azerbaijani

I benchmarked five Hugging Face models (SeamlessM4T v2, Whisper variants and Meta MMS) on a real Azerbaijani phone call in WAV and MP4. SeamlessM4T v2 was the most accurate. I wrapped it in a Python REST endpoint that converts audio with FFmpeg and returns JSON transcripts, and traced API-versus-script differences to missing decoding parameters.

  • Python
  • Hugging Face
  • REST API
  • FFmpeg
  • Azerbaijani

03 / VISION

Plant-health vision for Agrohub

For Agrohub, an agritech app for farmers, I compared more than ten plant-health APIs including Kindwise, Plantix and Agrio, and recommended Kindwise. Tested on crops grown in Azerbaijan, it identified the crop and its diseases from a single photo, with confidence scores and treatment advice in JSON.

  • Computer vision
  • Kindwise
  • Python
  • Agrohub
  • JSON

04 / PROJECT 1

Logic gates

With my team, we built three basic logic gates, AND, OR and NOT, on a breadboard, using transistors, resistors, push buttons and LEDs. A simple project, but it showed how computers are built from tiny switches.

05 / PROJECT 2

Hour of AI

With my team, I taught a one-hour AI and coding lesson at an education center for children who rarely get to use computers. We used Microsoft MakeCode so every child could snap blocks together and see their own program run. Everyone left with a certificate.

  • Microsoft MakeCode

  • Teaching

06 / PROJECT 3

Line-following robot with LEGO EV3

A team project in ADA's MakerSpace: we programmed a LEGO Mindstorms EV3 robot to find and follow a predefined line on its own, in MakeCode with Blocks and JavaScript, using the gyro sensor for accurate turns.
